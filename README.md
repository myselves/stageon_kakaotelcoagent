# 요금제 AI 추천 — Kakao Tools 프로토타입

카카오톡 안의 **ChatGPT for Kakao** 대화창에서 Kakao Tools `요금제 AI 추천`이 호출되어,
사전 크롤링된 요금제(모요 기준 알뜰폰 + 핀다이렉트 필수 + 통신 3사)를 비교해
고객에게 맞는 요금제를 추천하고 **AI 개통**까지 대행하는 흐름을 보여주는 모바일 웹 프로토타입입니다.

STAGE FIVE 제안서 「요금제 AI 추천 (Kakao Tools 서비스 제안) v6」의 STEP 1(인증 전 Top 5) · STEP 2(CASE A 조건 문답 / CASE B 마이데이터 자동 분석) · 요금제 상세 · 변경 시점 CTA 분기 시나리오를 구현했습니다.

## 실행

정적 파일이라 서버 없이 열 수 있습니다.

```bash
# 그냥 index.html 을 브라우저로 열거나
python3 -m http.server 8080   # → http://localhost:8080
```

모바일 뷰포트(390px 내외)에 맞춰 디자인했고, 데스크톱에서는 가운데 폰 프레임으로 표시됩니다.

## 시나리오 (대화창에서 해 볼 수 있는 것)

| 입력 | 동작 |
|---|---|
| `데이터 많이 쓰고 넷플릭스 자주 보는데 맞는 요금제 추천해줘` | 조건 추출 → Kakao Tools 호출 표시 → Top 5 카드 |
| `월 3만원대 데이터 많은 요금제 추천해줘` / `50기가 이상 저렴한 요금제` / `알뜰폰 중 통화 무제한` / `5G 무제한` / `KT망 LTE 7GB 싼거` | 예산·데이터·망·통화·사업자군 조건 파싱 후 추천 |
| `쓸만한 요금제 추천해줘` (조건 불명확) | 성향별 4타일 추천 카드 → 타일 탭 시 Top 5 |
| [조건 선택해서 찾기] | CASE A: 데이터 → 통화/문자 → OTT → 현재 납부 → 약정 순차 문답 → 조건 요약 → Top 5 |
| [마이데이터로 자동 분석] / `내 사용량 기반으로 추천해줘` | CASE B: 본인 인증 생략 → 3단계 분석 진행 → 지표 4종 요약 → 개인 맞춤 Top 5 (절감 배지) |
| [요금제 상세] | 바텀시트: 선택 조건(또는 현재 요금제) vs 추천 비교표 · 변경 시점(지금/3개월/6개월) · AI 추천 사유 3 · 분석 판단 근거 3 |
| 변경 시점 = 지금 → [AI 개통으로 요금제 변경하기] / 3·6개월 후 → [알림톡 받기] | A-05 CTA 분기 |
| [⚡ AI 개통 요청] | 가입 정보 확인 카드(마이데이터 자동 입력) → eSIM/유심 선택 → 4단계 개통 진행 → 완료 안내 |

## 추가 기능

- **AI 개통**: 모든 요금제 카드에 `⚡ AI 개통 가능` 아이콘을 표시하고, AI의 모든 답변 끝에 "가입부터 개통까지 제가 대행해 드릴 수 있어요" 안내 문구를 붙입니다. 카드 버튼으로 개통 대행 플로우가 시작됩니다.
- **카카오멤버십**: 상단 토글 "통신이용 혜택을 카카오멤버십으로 받기 (무료)". ON이면 모든 요금제 카드·상세·개통 정보에 `카카오멤버십 포함` 배지가 붙고, AI 답변에도 포함 안내가 들어갑니다.

## 데이터

- `js/data.js` — 요금제 스냅샷 102개. 알뜰폰 13개 사업자 × 8티어(LTE 7/15/11+매일2/100GB, 5G 10/20/50/110GB급)는 2026-07-31 모요(moyoplan.com)·사업자 공홈 수집 baseline이며 **핀다이렉트가 전 티어에 포함**됩니다. 통신 3사 9개는 공시 요금제 샘플(선택약정 25% 적용가). 각 요금제는 `promo`(가입 직후 월 납부액)·`reg`(정가)·`promoMonths`(할인 기간)를 분리해 12·24개월 평균 비용으로 비교합니다.
- `js/mydata.js` — 가상 통신 마이데이터(홍길동 · SKT 5GX 레귤러 · 최근 3개월 사용량/청구 · 선택약정 만료 · OTT 2종). 본인 인증·동의는 생략합니다.
- `js/engine.js` — 자연어 조건 파싱(`Engine.parse`)과 스코어링(`Engine.recommend`): 조건 필터 → 12개월 평균 비용 기준 정렬 → 오버스펙·QoS·LTE 전환 가중 → 사업자 중복 제거 Top 5.
- `js/app.js` — 대화 흐름·카드 렌더링·바텀시트·개통 스텝퍼.
